# Версия 12 (`v12`): безматричный 3D-движок на Vulkan API

Папка: `iterations/v12_vulkan_matrix_free_3d`.  
Ветка: `iter-12-vulkan-matrix-free-3d`, тег: `v12-vulkan-matrix-free-3d`.

---

## Что изменено и добавлено в v12

1. **Переход на кроссплатформенный Vulkan 1.2 (`GLSL 450 -> SPIR-V`)**:
   - Движок написан на чистом Си (`vulkan_matrix_free_3d_engine_v12.c`) и стандартных вычислительных шейдерах Vulkan (`membrane_collision_3d.comp`, `spatial_grid_rebuild.comp`, `render_3d_room_and_hud.comp`).
2. **Полный отказ от любых матричных умножений (`0 GEMM / 0 matmul`)**:
   - В шейдерах нет матричных типов и нет умножения на выходную матрицу словаря `head_w`.
   - Поля среды (плотность, температура, направление поля) хранятся в аппаратной воксельной 3D-текстуре (`sampler3D` / `image3D` $8\times 8\times 8$) и считываются текстурным блоком `TMU` за 1 такт, а след контекста записывается в воксели через `imageStore`.
   - Далёкие объекты отсекаются по видимой яркости (`71,5%–77,8%` объектов пропускаются без чтения памяти), а для оставшихся читается нужный уровень мип-пирамиды (`LOD 2`: 4 числа, `LOD 1`: 16 чисел, `LOD 0`: 64 числа).
   - Обучение идёт локально через закон сохранения импульса при столкновении на 2D-оболочке, с барьером синхронизации потоков, что даёт побитовую повторяемость на видеокарте `AMD Radeon Pro 5500M` (`max_abs_diff = 0`).

## Результаты замеров на полной валидации `WikiText-2` (`250 240` байт)

- **Ошибка на полной валидации (`2400` шагов обучения)**: `3,8273 ± 0,00500` бита на байт (`EMA(50)` на обучении — `3,894`).
- **Контроль по 5 сидам (`1..5`, по `800` шагов)**: `3,9896 ± 0,0410` бита на байт.
- **Фактическое чтение видеопамяти**: `6 951`–`8 291` байт на шаг вместо `65 536` байт у плотного чтения (реальная экономия трафика VRAM `87,35%–89,39%`, то есть в `7,9–9,4` раза меньше чтений).
- **Скорость на `AMD Radeon Pro 5500M`**: `638,0` шагов обучения в секунду, рендер кадра 1280×720 — `36,0` кадров/с.
