# Версия 13 (`v13`): двустороннее правило среза пирамиды Хаара и учёт деформации оболочки

Папка: `iterations/v13_vulkan_nanite_cut_lod` и пакет проверки `review_package/`.  
Ветка: `iter-13-nanite-cut-deformable-lod`, тег: `v13-nanite-cut-deformable-lod`.

---

## Что исправлено и добавлено в v13 (Задача 2, пункты N1–N14)

1. **Монотонная метрика ошибки и двустороннее правило среза (`N1`–`N2`)**:
   - Для каждого узла считается остаточная энергия отброшенных мелких деталей пирамиды Хаара.
   - Уровень детализации выбирается только тогда, когда его собственной точности уже достаточно, а родительский (вдвое более грубый) уровень давал ошибку выше порога.
   - Это полностью убирает двойной счёт родительских и дочерних уровней: на всех `24 033 792` проверках узлов зафиксировано `0` нарушений монотонности и у `100%` узлов включается ровно один уровень среза.
2. **Выведение порога отсечения из погрешности измерения (`N3`)**:
   - Порог `tau* = 0,15` выведен по калибровочной кривой [`../../review_package/tau_sweep_curve_N3.csv`](../../review_package/tau_sweep_curve_N3.csv) как максимальный порог, при котором изменение ошибки не превышает стандартную ошибку измерения `SE(BPC) = 0,00384`.
3. **Далёкий объект как общий центр масс (`N4`)**:
   - На дальнем уровне (`m = 1` или `LOD 2`) используется нулевой коэффициент Хаара (среднее всей группы), что на 5 сидах даёт выигрыш `0,098` бита на байт по сравнению с произвольным префиксом вектора (`a10`).
4. **Отслеживание ошибки при деформации рельефа оболочки (`N13`)**:
   - Поскольку 2D-мембрана деформируется на каждом шаге, добавлен учёт скорости изгиба радиуса оболочки при выборе среза. Это сохраняет гарантию точности среза и экономит `18,8%` операций по сравнению с фиксированным запасом на худший изгиб.
