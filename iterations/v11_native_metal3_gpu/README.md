# MarkovMembrane Engine (v11 — Metal 3 GPU)

Проверка работы архитектуры напрямую на шейдерах **Metal 3 (`Metal Shading Language`)** на видеокарте **AMD Radeon Pro 5500M (4 ГБ)** без PyTorch и без побайтового дробления (на уровне целых слов).

## Что внутри `metal_word3d_engine_v11.mm`

1. **Целые слова и роли `Субъект — Модулятор — Объект`**:
   - Текст `WikiText-2` разбирается на слова (словарь `2048` слов).
   - Слово-модулятор задаёт 3D-вектор углового момента и поворачивает 3D-оболочку по формуле Родрига прямо в шейдере.
2. **Полигональная 2D-мембрана в центре 3D-комнаты $(X, Y, Z)$ + `RGBL`**:
   - Разница между внутренним ожиданием и внешним словом меняет радиус вершин полигонов.
   - Через векторное произведение 3D-рёбер `cross(edge_u, edge_v)` считаются нормаль и площадь полигона, а также 4 канала `float4(R, G, B, L)` (цвет + яркость).
3. **Внешние узлы памяти в 3D-комнате без `KV-cache`**:
   - Остаток непогашенной ошибки обращается по лучу к 32 внешним узлам комнаты.
4. **Запись видео прямо с GPU**:
   - Шейдер `render_3d_room_and_2d_projection` рисует 3D-комнату с осями $X, Y, Z$ (слева) и 2D-проекции оболочки и осей (справа) в `training_3d_real_gpu_v11.mp4`.

## Сборка и запуск

```bash
clang++ -O3 -framework Metal -framework Foundation metal_word3d_engine_v11.mm -o markov_membrane_engine
./markov_membrane_engine ../lumen_nanite_3d_llm/wikitext_train_bytes.bin
```
