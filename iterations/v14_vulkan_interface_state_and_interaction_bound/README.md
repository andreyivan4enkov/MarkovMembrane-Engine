## Что исправлено и достроено в v14 (Задание 3, пункты S1–S4 и F1–F9)

1. **Отказ от сворачивания поверхности в 3 числа центроида и от усреднения по ошибке (`F8` + §3.1/§3.2/§3.3)**:
   - Вместо сжатия 64 секторов поверхности в одну точку `active_pos[3]` поверхность представлена иерархией площадок интерфейса.
   - Каждая площадка хранит как свою геометрию (3D-центр, радиус охватывающей сферы, нормаль, площадь), так и **состояние** (монопольную интенсивность и дипольный момент состояния вокруг центра площадки по FMM).
   - Усреднение площадок запускается только от перспективы по геометрическому критерию близости Барнса–Хата (`radius(g) / dist < theta`). При `theta -> 0` иерархический обход сходится к полному перебору `64 × 96 = 6144` пар с нулевым расхождением (`0,000e+00`).
2. **Критерий ошибки взаимодействия вместо ошибки сигнала (§4.1)**:
   - В двустороннем правиле среза вместо чистой энергии сигнала используется верхняя граница ошибки отклика самого признака, учитывающая массу входного вектора признака в отброшенном хвосте и норму выходного вектора признака.
3. **Точная инкрементальная граница ошибки при деформации вместо запаса `0,18` с руки (§4.2 / `F7`)**:
   - Используется линейность и ортонормированность преобразования Хаара: при изменении поверхностного сигнала на `delta_s` граница ошибки хвоста вычисляется напрямую из нормы приращения `||delta_s||_2` без свободных коэффициентов. На `144 202 176` проверках зафиксировано `0` нарушений.
4. **Каскад до сходимости по неизрасходованному остатку (`S4` / `F4`)**:
   - Фиксированные 3 волны заменены циклом до сходимости с порогом от средней ёмкости узлов; в отчёт выведена полная гистограмма фактического числа волн по шагам.
5. **Чистые счётчики и карта источников (`S2` / `F2`, `field_to_source_map.md`)**:
   - Из `mac_counted` убрана аналитическая добавка; параметры `Metal VRR` считываются напрямую из `review_package/metal_vrr_n8_result.json`; отклонение при подгрузке в стриминге измеряется напрямую без множителя `* 0,02`.
